02 / 核心流程

从想法开始，
把成果留下

需求、实现、判断和沉淀共同组成一套个人开发工作体系

01

想法输入

一个想法、一个需求、一个问题，或学习与创作过程中突然出现的灵感

学习想法 · 项目需求 · 算法问题 · 创作灵感
02

GPT 需求分析

通过多轮交流拆解目标、功能、场景和页面结构，整理成清晰的开发需求文档

产品分析 · 功能拆解 · 视觉规划
03

Codex 工程实现

读取项目结构，分析已有代码，完成 HTML、CSS、JavaScript 与组件开发，并运行测试

结构 · 样式 · 交互 · 文件管理
04

人工审美复核

查看真实效果，调整页面比例、空间布局、动画节奏和内容表达，去掉模板化痕迹

查看效果 → 提出意见 → GPT 整理 → Codex 优化
05

GitHub 资产沉淀

把源代码、文档、算法题解、项目记录和学习笔记保存为长期可检索的技术资产

代码 · 文档 · 题解 · 笔记
06

个人网站展示

将项目作品、算法题解、摄影作品、博客文章和技术记录公开展示，形成个人表达

GitHub → 网站 → 个人品牌
想法→需求设计→代码实现→人工复核→资产沉淀→公开展示
