01
想法 / 起点

先创建一个
属于自己的数字空间

最初的想法很简单：记录技术学习、算法成长以及个人创作，网站不是一份静态简历，而是一个会持续生长的个人档案

原因保持个人
特色
02
规划 / 结构

让不同兴趣
拥有自己的入口

主页、关于、项目、创作和博客构成基础骨架，每个页面先承担清晰的角色，再决定它应该长什么样

主页关于项目创作博客
03
设计 / 视觉

把秩序、颜色
和情绪放在一起

米白底色保留阅读感，彩色光晕负责情绪，清晰的网格和留白负责秩序，动效只在需要的时候出现，让页面有呼吸感

04
开发 / 实现

把设计变成
真实可用的交互

从 HTML 结构到 CSS 系统，再到 JavaScript 的细节交互，每一次编码，都是把抽象的体验变成可以被点击、滚动和使用的东西

组件↓交互↓优化
05
打磨 / 优化

让细节更轻，
让体验更顺

调整布局比例、优化图片加载、补齐移动端适配，也为每个页面补上明确的返回路径和错误状态

界面 / 布局性能响应式
06
上线 / 发布

从本地文件，
到公开的地址

代码进入 GitHub，页面通过 Cloudflare Pages 发布，上线不是终点，而是下一次迭代真正开始的地方

本地→GitHub→Cloudflare 在线
03 / 未来

Keep
building.

网站会继续变化，新的作品、新的学习记录，以及更多从想法走向现实的尝试，都会在这里留下痕迹

持续改进 +增加新的创作 +记录学习旅程 +构建更好的体验 +
