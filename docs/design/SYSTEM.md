# 设计系统说明

Northwind 使用明亮纸张色背景、黑色正文和粉/橙/黄/绿/青等功能性色。页面共享转场、滚动显现和交互边框，但每个专题页保留独立构图。

## 响应式边界

- 手机：320-480px
- 平板：481-1024px
- 桌面：1025px 及以上

布局必须避免页面级横向滚动。手机端降低背景模糊、指针跟随、持续 Canvas 和自动卡片切换；`prefers-reduced-motion` 下停止非必要动画并展示最终状态。

## 资源规则

- 首屏关键图片使用 `fetchpriority="high"`、明确尺寸和响应式 `srcset`。
- 非首屏图片使用 `loading="lazy"` 与 `decoding="async"`。
- 页面样式放在 `src/styles`，脚本按页面与共享模块拆分。
- 公共资源路径以生成后 HTML 所在的 `dist` 根目录为基准。
