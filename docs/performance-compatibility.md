# 性能与兼容性修复（2026-09-10）

## 运行策略

`src/scripts/shared/performance.js` 在页面动效之前检测设备条件。宽度不超过 1024px、粗指针触摸设备、最多 4 个逻辑核心、最多 4 GB 设备内存、省流量 / 2G 网络，或开启减少动态效果时，使用轻量展示。浏览器没有暴露硬件信息时不直接判为低性能。

- 挂绳进入视口后才导入 Three.js、Rapier 与模型。入口从 3,601,572 字节降至约 300 KB，另有约 12 KB 的共享依赖。3D 引擎仍在独立的延迟分块中，总体引擎体积没有消失。
- 手机与低性能设备保留可点击、翻面的资料卡，不加载 3D 资源。桌面 WebGL 不可用、模型或脚本失败、初始化超过 15 秒、上下文丢失时保留相同的替代展示。
- 模型纹理使用 HTML 图片加载器，避免 ImageBitmap 路径的 blob fetch 与 CSP 差异。未放宽生产 CSP。
- 挂绳离开视口、页面进入后台时停止渲染和物理更新。限制画布 DPR 与环境贴图分辨率。
- 图片网格不再逐帧创建 GSAP tween。球面菜单仅在可见时渲染，轻量模式在输入时重绘。修正 Hyperspeed 在高 DPR 下不断重设画布尺寸的问题。
- 手机资料卡改为正常文档布局，移除首次访问的桌面推荐弹窗；AI Lab 的手机和平板布局改为纵向阅读，取消横向滚轮接管。

## 首次音效

原代码把 `localStorage.getItem()` 返回的 `null` 转为数字 0，导致首次访问的默认音量被覆盖。现在没有保存值时保留 75%，已保存的静音状态仍受尊重。

音效按钮在 HTML 中提供初始展示，React 脚本失败时仍可开启音效。点击按钮启用音效并展开音量控制，滑块支持键盘，提供明确的静音切换。浏览器允许声音播放所需的用户点击仍然保留。音量控件移除了对 Chakra Provider 的依赖。

## 验证

- `npm run check`：构建、141 个发布文件检查、6 个运行时回归测试通过。
- Chromium / WebKit：320、390、768、1440px，7 个页面布局检查；除设计为横向的桌面 AI Lab 外，无页面级横向溢出。
- 两个引擎均使用本地 HTTPS 服务及原样生产 CSP 验证 3D 加载、模型失败替代和上下文丢失替代。
- 验证首次音效启用、键盘音量调节、音效脚本失败时的 HTML 控件、低核心数、禁用 WebGL、动态切换减少动效设置。
- 通过统计 WebGL 绘制调用验证挂绳屏幕外停止、回到视口后恢复。
- 外部 GitHub 实时题解数据受网络 / CORS 影响，不属于离线资源检查；WebKit 验证期间出现过外部请求失败。

以上是浏览器模拟与功能验证，未测量真实低端手机的帧率。可在目标手机上进一步测量滚动与拖拽表现。
