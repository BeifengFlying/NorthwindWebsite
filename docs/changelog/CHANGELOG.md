# 更新日志

## 2.0.1 - 2026-08-13

- 修复正式部署路径下首页关于我的 3D 挂绳卡片资源被解析到域名根路径，导致模型、挂绳与卡片贴图不显示的问题。
- 优化手机端导航菜单的液态玻璃适配，去除菜单文字下面的实体磨砂玻璃底色、边框和阴影。
- 本地完成桌面与手机视口验收，Canvas、模型资源和菜单渲染无控制台错误。

## 2.0.0 - 2026-08-13

- 发布重大版本 `v2.0.0`，统一 npm 包版本与发布资源缓存序列，并升级 `sharp` 清除高危依赖漏洞。
- 首页加入互动挂绳资料卡、可拖拽贴纸、液态玻璃导航与音量控制、专辑倾斜卡片和 GitHub 联系二维码。
- AI Lab 重构为横向实验画布，加入极光背景、部署步骤、实验笔记、模型与硬件记录、格式比较和演进时间线。
- 摄影页改为键盘可用的手风琴作品集；题解、开发旅程、工作流、404 和全站导航同步完成新组件、背景及响应式更新。
- 收敛页面转场、标题和区块显现动效，减少大幅位移和模糊，提升快速滚动时的可读性，并保持减少动态效果偏好。
- 工作流页的循环卡片更新为可见区域内的可访问轮播：支持键盘访问、焦点暂停、页面可见性和响应式状态切换。
- 修正发布资源检查：互动挂绳模型拥有受限的专用大小阈值，其他资源继续采用默认发布上限。

## 1.2.1 - 2026-08-06

- 增加首页 `The Path Beneath Our Feet` 模块的中英双语编辑式布局，采用四行英文主标题、描边字、编号正文和错位排版，并完成 320px / 390px 手机适配。
- 移除首页背景路线线条，保留无灰框的留白层次；将动态星空背景与漂移、路线摆动和滚动衍生效果迁移到 AI Lab。
- 完善首页与 AI Lab 的中英文语言切换，保护双语对应文案和品牌化英文内容不被自动误译。

## 1.2.0 - 2026-08-01

- 增加完整中英文双语切换能力，并将语言内容集中到统一 JSON 数据中。
- 统一全站导航的三段式布局，修复窄屏溢出、返回链接越界和英文标题残留。
- 增加首页 Bubble Menu 风格气泡导航、透明展开层与逐项弹出动画。
- 优化题解与 AI Lab 深色页面的背景对比和低分辨率可读性。
- 保留音乐名称与品牌化英文表达，避免误翻译既有设计语言。
