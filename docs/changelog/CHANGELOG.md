# 更新日志

## 1.2.0 - 2026-08-01

- 增加完整中英文双语切换能力，并将语言内容集中到统一 JSON 数据中。
- 统一全站导航的三段式布局，修复窄屏溢出、返回链接越界和英文标题残留。
- 增加首页 Bubble Menu 风格气泡导航、透明展开层与逐项弹出动画。
- 优化题解与 AI Lab 深色页面的背景对比和低分辨率可读性。
- 保留音乐名称与品牌化英文表达，避免误翻译既有设计语言。

## Unreleased

- 修复首次打开首页时音频上下文未获得有效手势授权、需往返子页面后才有声音的问题，并将音频文件预取与上下文创建解耦。
- 修复 Edge 滚动首页时固定彩色光晕的合成层闪烁，取消冲突的滚动视差并稳定其渲染层。
- 修复首次进入时声音开关因延后绑定而反馈迟缓的问题，改为首屏渲染前绑定事件、即时双向切换，并为移动端启用直接触控响应。
- 恢复最初的音乐轮盘刻度声与页面转场声，声音开关移至页面右下角并改为无提示音的持久化双向开关，同时将纸飞机风声调整为轻微莎莎声。
- 增加首页声音开关以满足 Safari 音频授权要求，并对音效相关资源进行显式缓存破坏。
- 将页面转场音效改为遮罩开始 620 毫秒后触发，避免音效领先视觉动画。
- 将轮盘刻度声和纸飞机风声改为预加载的公开静态音频资源，并进一步后移页面切换音效。
- 同步页面切换动画与音效，并为首页纸飞机滚动过场增加双向风声。
- 恢复 Cloudflare 部署后的音乐轮盘刻度声，统一使用按用户手势解锁的 Web Audio 引擎。
- 调整未哈希静态资源缓存策略，确保新部署的脚本能够及时生效。
- 改进首页手机端菜单、内容间距、音乐轮盘、滚动显现性能与横向溢出控制。
- 外部动效 CDN 不可用时，首页音乐轮盘仍可独立运行。
- 增加自定义非商业源码许可证，并明确原创与第三方素材不授予复用许可。
- 完善私有素材、源文件格式与本地配置的 Git 忽略规则。
- 将仓库文档和部署流程更新为 Public GitHub 仓库与 Cloudflare Pages。
- 在网站页脚增加统一版权声明。

## 1.0.1 - 2026-07-30

- 修复音乐轮盘快速拖动时音效排队、首次播放延迟和声音与视觉刻度不同步的问题。

## 1.0.0 - 2026-07-30

- 将扁平静态项目重构为 `src`、`public`、`scripts`、`docs` 和本地私有资源目录。
- 拆分摄影页内联样式与脚本，统一页面和共享资源边界。
- 摄影图片生成 640/1280/1920 响应式 WebP，音乐封面生成 480px WebP。
- 从发布资源移除 EXIF、GPS、原始 DNG、大尺寸未使用封面和个人联系方式。
- 增加移动端动画降级、懒加载、尺寸提示和静态资源缓存配置。
- 增加构建、预览、安全/断链检查和 GitHub Actions 配置。
